#  MERN E-Commerce Platform

A full-stack, production-ready e-commerce solution built with the MERN stack (MongoDB, Express.js, React, Node.js). Features a powerful admin panel, secure payment integration, cloud deployment, and automated email notifications.



---

##  Features

###  Customer-Facing Features
- **Responsive Design** - Mobile-first, modern UI with Tailwind CSS
- **Product Catalog** - Advanced filtering, sorting, and search functionality
- **Shopping Cart** - Persistent cart with real-time updates
- **User Authentication** - JWT-based secure login/signup
- **Checkout Process** - Multi-step checkout with address management
- **Order Tracking** - Real-time order status updates
- **Payment Integration** - Multiple payment methods (Cash on Delivery, Net Banking, UPI)
- **Auto-Image Slider** - Dynamic hero banners with smooth transitions

###  Admin Panel Features
- **Dashboard Analytics** - Sales metrics, order statistics, and user insights
- **Product Management** - CRUD operations with image upload
- **Order Management** - Update order statuses and track fulfillment
- **User Management** - View and manage customer accounts
- **Category & Brand Management** - Dynamic filter configuration

### Technical Highlights
- **Redux Toolkit** - Centralized state management with async thunks
- **RESTful API** - Clean, documented API endpoints
- **Cloud Deployment** - Production-ready deployment configuration
- **Email Notifications** - Automated order confirmations and updates
- **Image Optimization** - Cloud-based image storage and delivery
- **Responsive UI** - Tailwind CSS with custom components
